# lau-tensor-midi

Tensor field MIDI engine for reactive improvisation.

Rooted in the Chinese mathematical tradition — I Ching hexagrams, Taoist conservation of chi, the Book of Changes as a tensor field of possibility.

Every conversation is music. Every agent has a rhythm. The system breathes.

## Core Mathematics

A MIDI tensor `T ∈ ℝ^{B×A×N}` where:
- **B** = bars
- **A** = agents
- **N** = note-dimensions (pitch, velocity, duration, onset, channel)

The tensor field encodes the full musical state of a conversation.

## Taoist Principles

- **BPM adapts to energy** — the system flows. Wu-wei: the system does not force timing, it reveals timing.
- **Conservation of chi** — total energy in ≈ energy out + energy stored
- **Reactive nudges** — excitement, pushback, questions, topic shifts, silence
